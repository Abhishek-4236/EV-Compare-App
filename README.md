## 🛠️ Tech Stack
- Frontend: React.js (Vite)
- Backend: FastAPI (Python)
- Database: PostgreSQL
- Charts: Chart.js

## ✨ Features
- Filter EVs by price, range, brand
- Compare 3 vehicles side by side
- FAME II + State subsidy calculator
- 5-year cost chart
- Smart recommendation wizard

## 📊 Dataset
- 50+ Indian EV models across 5 segments
- Segments: 2W, 3W, 4W, Bus, Truck
- 6 Indian state subsidies included
